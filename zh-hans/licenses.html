3. 第三方 SDK 与库

Times Rush iOS 应用程序集成多项可信赖的第三方服务，用于支持使用分析、崩溃报告、广告展示以及应用性能监控。

上述第三方服务均依其各自的许可条款和使用规范运行。

3.1 Firebase（Google LLC）

本应用程序可能使用以下 Firebase 服务：

  • Firebase Analytics
  • Firebase Crashlytics
  • Firebase Remote Config
  • Firebase Performance Monitoring

Firebase 由 Google LLC 拥有并运营。 许可条款说明：https://firebase.google.com/terms

3.2 Google AdMob

Times Rush 使用 Google AdMob 展示广告内容。

AdMob 可能根据用户所在地区、同意状态以及设备设置，收集特定设备标识信息，用于提供个性化或非个性化广告，并进行效果衡量与防欺诈用途。

相关政策：https://policies.google.com/technologies/ads

3.3 Apple 官方框架

Times Rush 使用 Apple 官方提供的系统框架，包括但不限于：

  • Swift
  • UIKit
  • StoreKit
  • AVFoundation

上述框架均依据 Apple 平台相关许可条款提供。

3.4 开源组件

Times Rush 可能使用部分开源 Swift 包或库，其使用受各自许可条款（如 MIT、Apache 2.0、BSD 等）约束。

如相关许可条款有要求，对应的开源声明将会在应用程序内或随附文档中提供。

3.5 Microsoft Azure 语音服务

Times Rush 使用 Microsoft Azure AI 语音服务（Text-to-Speech）生成语音内容。

通过 Azure 语音服务生成的音频，在符合 Microsoft Azure Cognitive Services 许可条款及相关政策（包括 Responsible AI 与语音服务规范）的前提下，可用于商业用途。
